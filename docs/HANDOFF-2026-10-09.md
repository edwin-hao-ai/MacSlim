### 核心语义（改动的关键，别回退）
清理结果拆成三个**语义不重叠**的口径，**只有实测的能叫「释放」**：
- `deleted_bytes`：成功**永久删除**的条目体积之和（缓存主口径）
- `trashed_bytes`：成功**移入废纸篓**（尚未释放）的体积之和（卸载主口径）
- `reclaimed_bytes: Option<u64>`：卷可用空间的**实测**增量（`statfs` 前后差 − 噪声下限 4 MiB）。读不到就是 `None`，**绝不伪装成 0**。
- 历史库**只加列**（`reclaimed_bytes` 可空、`deleted_bytes`/`trashed_bytes`），旧 `freed_bytes` 保留兜底；旧行 `reclaimed` 为 NULL。
- 前端铁律：`reclaimed` 为 null 时显示「已删除（未能测量释放）」，**不**把 deleted 冒充实释放；卸载显示「已移入废纸篓，尚未释放」。
- 缓存页新增安全筛选 chips：全部 / 可安全清理 / 需先复核（⌘1–3），**纯视图层**，不影响默认勾选与门禁。

## 三、vgoapp.com 全站 SEO

仓库：`/Users/edwinhao/VGOAPP`（remote `edwin-hao-ai/VGOAPP`），Caddy 托管在 VPS `158.247.219.230:/var/www/vgoapp`，部署用 `scripts/deploy.sh`。

### 根因修复
- **全站预渲染（SSG）**：原来 17 个页面都是 CSR（HTML 里只有 `<div id="root">`），Google 要执行 JS 才看得到内容 → 索引慢/不全。新增 `scripts/prerender.sh`（无头 Chrome dump-dom），接入 `npm run build`。现在 **34 页**（17 中 + 17 英）HTML 里直接带正文。
- **移除无效 hreflang**：14 个页面 `zh` 与 `en` 都指向同一 URL（Google 忽略）。

### 双语 SEO（语言路径）
- **语言由 URL 路径决定**：根路径 = 中文（主语言），`/en/*` = 英文。`LanguageContext` 按 `location.pathname` 判语言；切换语言 = 跳到对应路径。
- `scripts/i18n-routes.py`：构建时给每个中文路由生成 `/en/` 镜像 + 双方 hreflang（zh-Hans/en/x-default）+ 按语言的 `og:locale` 与 `keywords` + 生成完整 `sitemap.xml`（34 URL + 68 条 hreflang）。
- Navbar 在 `/en/` 页自动给返回/Logo 链接加 `/en` 前缀。

### 内链 / 结构化数据
- 首页 MacSlim 产品卡与 Footer 从 GitHub 改链到 `/macslim/`（此前 `/macslim/` 无内链，GSC 报「未检测到引荐来源网页」）。
