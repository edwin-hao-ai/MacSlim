MacSlim 支持

需要帮忙？先看下面这三条，九成问题都在这里。

缓存清理扫不出东西？

App Store 版受系统沙箱限制，只读取你亲手授权的目录。 打开「缓存清理」页，点对应目录的「授权」，在系统弹出的文件选择框里 选中它，然后再点「重新扫描」。

找不到「结束进程」按钮？

沙箱不允许应用给其他进程发信号，App Store 版因此只提供只读 的进程监控：可以看到每个进程的 CPU 与内存，但不能代替你终止它。 需要这项能力请用官网的完整版。

清理会不会误删？

「重新获取成本低于 5 分钟」的项目才会默认选中，例如应用缓存、日志、 Xcode 编译缓存。完整镜像、整份 node_modules 这类大件不会默认选中。每一项在执行前都会二次校验路径。

两个版本的区别

  • Mac App Store 版（本应用）：系统监控、进程监控、 应用体积与卸载、文件夹授权后的缓存清理。更新由 App Store 负责。
  • 完整版（官网下载）：在上述基础上增加终止进程、 Docker 清理、端口占用，以及不需要逐个授权文件夹的缓存清理。
